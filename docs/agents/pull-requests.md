- **Open every pull request as a draft, with `pnpm open-pr --title "…" --body-file …`.** `.claude/hooks/require-draft-pr.sh` blocks the raw `gh` create command. CI runs the whole gate on `ready_for_review`, so a draft spends no minutes. "Ready" then says one thing: up for review, and meant to merge. **`pnpm open-pr --ready` is that decision** — it works on a draft the branch already has, and it prints the `pr-wait` command next. `gh pr ready <n>` is the call underneath and is not blocked.
- Watch the result with `pnpm pr-wait <n>`. Read `docs/agents/ci.md` for the verdict-line rule.

FreeGantt — S4 hierarchy, row sources, pack lanes & rollup

One Gantt, one fixture (fixtures/hierarchy-dataset.ts). The controls below exercise live row re-resolution, pack-mode heights, tree collapse, declared-field rollup, and JSON round-trip — with every committed changeset logged the same way data.html does (D-S2-17). Drag a column edge to resize it or a header cell to reorder it (S5.7, D-S5-18) — a focused header cell also takes Shift+Arrow to resize and Alt+Arrow to move. Double-click Name, Start or Cost to edit in place (S5.8, D-S5-19) — Enter or blur commits one transaction, Escape reverts. End stays read-only on purpose: a column is editable only when you say so.

FreeGantt — an owning parent (#470)

Phase declares { key: 'start', rollUp: 'none' } and the same for end — a Dataset-wide opt-out of the Rollup for both date Fields. Phase keeps the dates it is given: drag its bar and it moves like an ordinary bar, its two children with it. Drag its end handle and only Phase's own end changes — the children keep their span, because a resize never stretches a subtree (#470).

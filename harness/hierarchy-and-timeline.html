With this box on, a plugin decides each row's parent from a phase id (ADR 0020). Vertical drag stays off for an ordinary row, because the plugin would not follow a parentId write. A children-as-segments row, like Framing crew, still takes an into drop, and that drop writes parentId when the row has no phase id. Issue #606 tracks a full fix.

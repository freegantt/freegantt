FreeGantt — grid pane scroll (#126, #139)

Four fixed-width columns (120px each) in a 220px grid pane: the pane's content is wider than itself, so .fg-grid-pane is a real horizontal scroller (D-S1.8-13). Hovering either pane and using a plain mouse wheel also scrolls rows vertically.

#139 — the same overflow, with no width authored anywhere

The same four columns, this time written as bare field names. Every Grid column is fixed-width by default, so the set overflows the 220px pane and scrolls exactly as the one above does. The third Gantt drops to two columns and asks its Name column to flex, which is the opt-out: Name takes whatever room the fixed Start column beside it leaves, and nothing overflows.

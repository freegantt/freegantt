Vetoes

A drop before the dashed Mobilization line is refused. Lock an entry and every edit to that row is refused too. Its children stay free: drag one out of a locked parent and it moves.

Per-entry lock rule (#473)

The Note field is locked (editable: false) everywhere. A plugin's setLockRule opens it under each subtree it names — sharper than the Field itself, and read by every write door, so the button below refuses the same rows the lock rule does.

Plugins

Three plugins over the public contract: bufferKind()/riskKind() paint their own bar kind and menu item, overBudgetRows() stripes a whole row, and Mod+K clears the selection through a plugin-registered chord.

Document

Round-trips the whole Dataset through the public toInput()/add() pair. Import replaces every entry and clears undo. Sync all diffs a fetched list against the live data instead, keeps a kept row's selection and collapse state, and records no undo step — your own edits stay undoable across a poll. Sync changes applies only the rows a server changed and keeps every key a row leaves out. An undo never writes over a value a sync brought in.

bufferKind() (S5.9, D-S5-21/D-S5-22, [S5-A3], ADR 0018): a consumer-defined 'buffer' variant — harness/plugins/buffer-kind.ts, zero core edits, zero private imports. One ctx.variants.add call answers all four questions in one object: when (which rows wear it), items (what shape it draws), paint (the hatched fill) and can (no resize handle). One ctx.commands.register adds its own right-click item, scoped to the variant by when: ({ variant }) => …. Uncheck "Custom milestone + cost renderers" to see this page's own variants entry hand the hatch back to the plugin's — same pixels, and a consumer's rules outranking every plugin's is what changes hands.

riskKind() (review P2): a second kind-defining plugin — harness/plugins/risk-kind.ts. It registers ctx.view.registerRenderer('bar', …) for its own kind while bufferKind() holds that point for its own. The bar point keys on the kind, so both plugins install and both paint. "Drop riskKind" removes one of the two: the buffer hatch stays exactly as it was.

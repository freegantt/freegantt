FreeGantt — theme resolver

The Gantt below never sees data-fg-theme: this page signals dark mode the way Tailwind, Filament, and next-themes do, with a dark class on <html>. A ThemeResolver (#433) reads that class instead of the built-in 'auto' pin/OS pair. Toggling the class flips the Gantt with no assignment of its own.

1What this is, and how it stays true

API Extractor reads dist/api/index.d.ts and writes every @public export — its full type signature, no summary — to etc/freegantt.api.md. pnpm api-report fails the moment that file drifts from the built types (I11, plans/04 §2), so the report a maintainer commits is the same report a consumer's editor resolves.

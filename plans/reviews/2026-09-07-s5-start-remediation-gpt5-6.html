Recommendation summary

Fix runtime defects before architecture debt.

Keep app-author and plugin-author interfaces separate.

Use existing internal seams. Do not add a new public hook for preview resolution.

Make invalid authored states fail in TypeScript. Keep resolved internal shapes simple.

Test each extracted module through its interface. Do not test through GanttShell when a smaller seam exists.

Three corrected recommendations

A2 · Use an internal friend seam

The first report suggested a plugin wiring surface. That surface has no honest external caller.

Use ADR 0007's private WeakMap pattern instead. The public Dataset then loses the core-only method.

R1 · Require reasons, not local key types

Valid caches use Intl.DateTimeFormatOptions, ViewPreset headers, and DOM Elements as keys.

A local-type rule rejects good caches. A required reason makes each exception reviewable.

R3 · Resolve defaults before deleting state

The current getter can return an omitted heightMode. The harness must not re-derive its default.

Return the resolved setting first. Then the harness can read one reliable source.

Problem. resolveColumns and resolveFieldCompares split one locale bind. Shell wires only columns. lookupFrom is a second adapter at FieldLookup.

Solution. Deepen: bindGanttFields(lookup, gridColumns, bind) → { columns, fieldCompares }. Pass dataset.field. Delete the Map rebuild.

  • Locality: locale bind lives in one module
  • Leverage: S4.9 sort reuses the same call
  • One adapter at FieldLookup

ADR 0005 aligned. Do not move formatValue or merge into layout/.

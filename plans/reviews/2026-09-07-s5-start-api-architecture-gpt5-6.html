HIGHT1-1 · The opacity token breaks per-bar colors

src/view/styles.ts:89-90, 209-216

Problem. The container computes --fg-bar-fill-painted from its own fill. Descendant bar overrides cannot change that inherited value.

Evidence. Chromium painted a purple test bar with the container blue. The old rule painted rgb(123, 44, 191).

Rule. Plans/02 §4 says each Token override must win. S5.4 also requires renderer colors through --fg-bar-fill.

Fix. Compute the color mix on each bar shape. Add a computed-color browser assertion.

MEDIUMT1-2 · After-events expose a live refusal function

src/view/gesture-pipeline.ts:253-280

Problem. One payload serves both event phases. Runtime entryMove and entryResize payloads contain refuse.

Rule. src/model/error-report.ts:70-73 limits Refusable to before*. Plans/02 §3 gives after-events no veto.

Fix. Build a plain after-payload. Add refuse only to the before-payload.

MEDIUMT1-3 · ErrorCode omits shipped editor codes

src/model/error-report.ts:38-56 · src/extensions/features/inline-editing.ts:157-160, 409

Problem. The union omits unreadable-value, refused-write, and segmented-entry.

Rule. Plans/02 §4 states that each editor reason is also its Error report code.

Fix. Add all three literals beside the other editor codes. Add an exhaustive built-in-code test.

MEDIUMT1-4 · The data demo loses error reports after import

harness/data.ts:143-156, 241-249

Problem. watchAllErrors subscribes once. Import replaces both Dataset and Gantt instances.

Rule. The harness stop rule forbids consumer compensation. This also breaks the page's rebind proof.

Fix. Rebind the error watcher with the new instances. Dispose its prior subscription first.

TESTT1-5 · The shared-envelope conflict path has no test

src/data/build-commit-change-set.ts:89, 164-176

Problem. Tests cover agreeing body and extender writes. They do not cover conflicting Segment and envelope writes.

Rule. The data rule requires one atomic result. D-S5-49 records this merge.

Fix. Assert SegmentsOutOfSyncError and no commit for the conflicting path.

TESTT1-6 · The I5 cache fix has no regression guard

src/view/gantt-shell.ts:399-401, 1346-1355

Problem. The shell caches a by-id map, but no test guards map identity or invalidation.

Rule. Plans/01 §11 I5 forbids allocation during drag preview.

Fix. Assert stable map identity per revision. Assert invalidation after commit and without a revision.

TESTT1-7 · SegmentSelection lacks focused unit tests

src/view/segment-selection.ts:1-199

Problem. Shell tests cover integration. They do not pin the extracted object's ordering and mixed-owner rules.

Rule. CLAUDE.md requires one clear job. Focused tests protect that new boundary.

src/api/dataset.ts:244-253

MEDIUMA3 · PluginStore requires branded input

src/model/plugin.ts:35-49

Call. ctx.store.reserve<Lock>().set(entryId('t2'), lock)

Problem. Plugin authors must brand ids, while dataset.entries.get('t2') accepts strings.

Rule. Plans/02 §2.1 requires loose input on every input path, including get.

Fix. Accept EntryId | string on get, set, and remove. Brand inside data/.

MEDIUMA4 · GridColumn permits width and flex together

src/model/field.ts:70-77 · src/layout/column.ts:50-70 · src/layout/frame.ts:281-290

Call. { field: 'cost', width: 120, flex: 1 }

Problem. Measurement treats this column as fixed. Paint also gives it flex behavior.

Rule. CLAUDE.md requires illegal combinations to be unrepresentable.

Fix. Use a union with width?: never and flex?: never on opposite branches.

MEDIUMA5 · Two getters return input types

src/api/gantt.ts:530-550

Call. diffMs(gantt.dateLines[0].placeAt, now()) does not type-check.

Problem. The shell stores Instants. The getters widen them back to InstantInput.

Rule. Plans/02 §2.1 requires loose input and complete stored output.

Fix. Return boolean | Instant. Publish a resolved Date line output type.

MEDIUMA6 · RaiseError is a public internal port

src/model/error-report.ts:122-133 · src/api/index.ts:38-46

Rule. CLAUDE.md permits only useful api/ and model/ types on the public surface.

Fix. Remove the barrel export. Keep the type available to internal modules.

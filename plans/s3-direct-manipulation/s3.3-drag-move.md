# S3.3 — Drag-move

**Slice:** S3 · **Step:** 3 of 8 · **Spec:** [`README.md`](./README.md) · **Decisions:** D-S3-2, D-S3-3, D-S3-4, D-S3-5, D-S3-6 (preview), D-S3-11, D-S3-16, D-S3-18 (no extender yet), D-S3-19, D-S3-21, D-S3-22 (move events)
**Prerequisite:** none · **Status:** not started · **Ends with:** bars drag, snap, commit, and Ctrl+Z reverts them.

## 1. Decisions

### D-S3-2 — A Draft **is** `EntryEdits`. There is no new draft type

A gesture holds `EntryEdits` (`ReadonlyMap<EntryId, StoredEdit>`). **Draft** is glossary for gesture state, not a type. Distinct from **Write set** (inside an open `transaction()`). Uses `StoredEdit` (Instants), not public `EntryEdit`.

### D-S3-3 — Calendar delta, not pixel delta

Snap pointer to whole snap units; step both ends through zone-aware `stepBy` in `time/`. Preserves wall clock across DST. `snap: 'none'` falls back to milliseconds.

### D-S3-4 — Gesture math in `layout/gesture-draft.ts`

```ts
export function draftForMove(input: DraftInput): EntryEdits;
export function previewOffsets(input: { proposed, extra, entries, scale }): readonly ItemPreview[];
export interface ItemPreview { itemId, dx, dWidth, extra: boolean }
```

`EntryEdits`/`StoredEdit` move to `model/entry.ts`; `data/` re-exports. `interaction/` performs no arithmetic — receives drafts through context.

### D-S3-5 — `EntryGestureContext` (seven members)

```ts
export type Gesture = { kind: 'move' } | { kind: 'resize'; edge: 'start' | 'end' };
export interface EntryGestureContext {
  entryFor(itemId): Entry | undefined;
  can(capability: keyof Interactions, entry): boolean;
  entriesForGesture(grabbed): readonly Entry[];
  draftFor(gesture, entries, byPx): EntryEdits;
  commit(gesture, draft): Promise<boolean>;
  preview(draft: EntryEdits | undefined): void;
  pointerAt(at: { itemId?, x? } | undefined): void;
  selection: { get(), propose(next) };
}
```

Grow `entry-gestures.ts` in place — one pointer stream, not three attachments. `SplitterHooks` → `SplitterContext` (mechanical).

### D-S3-11 — Horizontal only

Vertical dy is ignored; no row reorder or reparent in S3.

### D-S3-16 — One transaction per gesture

`beforeEntryMove` (Gantt, may async) → `dataset.transaction()` with one `update()` per draft row → `entryMove`. `MutationCancelledError` from `beforeChange` restores silently.

### D-S3-18 — Preview coalesced on shell rAF (extender not called yet)

### D-S3-19 — Multi-selection move

Dragging a selected bar moves all capable selected entries; dragging outside selection moves only it. Incapable entries skipped, not blocking.

### D-S3-21 — Touch long-press (400ms) on coarse pointers; `touch-action: none` on bars/handles only

### D-S3-22 — Move events

```ts
export interface ProposedSpan { entry, start, end }
export interface EntryMove extends ProposedSpan {
  readonly entries: readonly ProposedSpan[];  // grabbed first; extender extras NOT included
}
```

## 1. Decisions

### D-S3-18 — Extender preview once per rAF

```
pointermove → draft (last wins)
rAF → extra = extender({ entries: committed, proposed: draft })
    → previewOffsets({ proposed, extra, entries, scale })
    → applyState
```

Same `EditRequest` shape as commit. `entries` is committed snapshot. `ItemPreview.extra` distinguishes `ghost` from `dragging` tokens.

### P1 — No public extender install API in S3

Tests inject through internal `DatasetStateOptions.editExtender` (D-S2-6). Harness lock-style demo moves to S5.
